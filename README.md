# SugarSee · 见糖

**不是戒糖，是先看见糖。** / See the sugar you don't see.

SugarSee 是一个优先考虑 ADHD 友好体验的糖分可视化记录产品。它让用户低负担地记录吃喝，理解糖摄入，并在周报、月报中看到自己的习惯变化。

## 已确定
- 中文名：见糖；英文工作名：SugarSee（品牌可用性尚待核查）。
- 核心主张：先看见糖，而非惩罚式戒糖。
- 核心场景：上传食物/饮料照片、搜索或手动记录；可视化糖摄入；周报与月报。
- ADHD 友好：少步骤、强视觉反馈、无需连续打卡、不制造羞耻。
- 未来考虑：商品数据库、会员、AI 可视化、皮肤/精力/睡眠自我观察。
