# 数据口径、健康与 AI 边界

## 糖数据
- 必须区分「总糖」「添加糖」「游离糖」；不同地区标签口径不一致。没有足够数据时明确写「糖（总量）」或「估计糖量」，不擅自等同添加糖。
- 记录份量与单位（每 100ml / 每份 / 实际饮用量），不同甜度、冰量、配方、地区会改变数值。
- 数据优先级：可验证的包装标签或品牌官方资料 → 可信数据库 → 用户自行填写 → AI 估计。保留来源、时间、地区、版本、置信度。
- 识别失败时必须允许手动修正，不能编造精确克数。
- 方糖视觉换算约 4g/颗，仅用于直观表达，标注假设。
- 对目标额度的提示应区分公共健康指南和个体建议，不能为所有人设同一个「安全上限」。

## 健康表述
- 不能声称糖直接导致 ADHD、脂溢性皮炎、所有炎症、肢体焦虑或个体皮肤变化；不能保证减少糖后会改善这些问题。
- 记录皮肤、睡眠、精力是个人观察，相关不代表因果。
- 不通过照片估算血糖或生成伪医学预测。
- 避免「今天超标，你的皮肤会变差」等恐吓性文案。
- 不能鼓励极端戒糖、补偿性运动或限制饮食；对有饮食困扰的用户提供柔和、非评判体验。

## AI 图像
- 可生成清晰标记的概念图、方糖视觉、趣味分享卡。
- 自拍前后对比优先展示真实、用户授权的时间序列；若使用生成图，必须醒目标注「AI 示意，非真实预测」，不作为医学或美容效果承诺。

## 隐私
- 食物照片、自拍、皮肤记录、健康指标均按敏感数据审慎处理。
- 默认私密，明确同意才上传云端或调用第三方 AI；提供删除、导出和保留期限控制。
- 不默认公开报告，不将个人健康信息用于广告定向。
- 未来上线前需针对目标地区完成法律、平台政策与安全评估。
