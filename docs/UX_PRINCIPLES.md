# 体验与视觉原则

## 核心
- ADHD 友好是设计目标，不把 ADHD 用户描述成同质群体。
- 首页 1 秒理解今日已记录多少糖；3 个动作以内完成常用记录是设计目标（待测试）。
- 少字、多图、明确的主按钮；优先卡片、图表、对比而非大段健康文章。
- 可跳过、可补记、可撤销、可修改；不因中断连续打卡而惩罚。
- 视觉冲击用于理解数量，不用红色警报、恐吓文案或羞辱式排行榜。
- 支持减少动画、颜色对比、字号和屏幕阅读器；不依赖颜色单独传递信息。

## 初步视觉方向
- 开心果绿、奶油白、深森林绿；不使用传统医疗蓝作为主调。
- SugarSee 视觉符号可探索眼睛、方糖、放大镜的组合；当前没有正式 Logo。
- 页面候选：今日 / 快速记录 / 糖时间线 / 报告 / 我的。
- 首页优先「已记录糖量」「视觉等价物」「快速记录」；趋势在第二层。
- 商品结果应包含份量、糖量、来源、可信度、是否为估算。
- 报告图表支持分享，但默认不公开个人健康数据。

## 待产出
线框图、真实饮料记录场景、移动端可用性测试、空状态与错误状态、设计 tokens。不要把示意数据当成真实产品营养数据。
